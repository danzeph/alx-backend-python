# 0x03. Unittests and Integration Tests

## Description
This project focuses on writing **unit tests** and **integration tests** in Python using the built-in `unittest` framework. The goal is to understand the difference between unit and integration testing, and to practice common testing patterns such as **mocking**, **parameterization**, **fixtures**, and **memoization**.

All tests are written to validate the behavior of existing code without modifying the original implementation.

---

## Learning Objectives
At the end of this project, I am able to explain:

- The difference between **unit tests** and **integration tests**
- How to use `unittest` and `unittest.mock`
- How to mock:
  - Functions
  - Methods
  - Properties
  - External HTTP requests
- How to parameterize tests
- How memoization works and how to test it
- How to write integration tests using fixtures
